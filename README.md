# N90
Plataforma para fútbol amateur que conecta jugadores, equipos, árbitros y ligas. Permite gestionar registros, partidos, estadísticas, resultados, tarjetas, rankings y el historial deportivo de cada jugador en un solo lugar.


# Roles de usuario

- Administrador de liga
- Jugador
- Administrador / DT
- Árbitro
